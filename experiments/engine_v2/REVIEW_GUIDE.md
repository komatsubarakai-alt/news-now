# 15組のスマホ確認ガイド

`review.html` は単一ファイルで動作します。テンプレートと生成器は開発用で、利用時はHTMLだけを保存してください。

1. PR #17の作業ブランチの `experiments/engine_v2/review.html` をダウンロードします（GitHubファイル画面のDownload raw file）。
2. スマートフォンのJavaScript対応ブラウザで開きます。ファイルのプレビューだけではボタンが動かない場合があります。実機のiPhone・Androidでの動作は未確認です。
3. 「確認する組を選ぶ」から対象へ移動し、見出し・保存引用・出典・事件IDを比較します。URLは折りたたんで表示できます。本文確認は自分で確認した場合だけチェックします。
4. 「同一事件」「別事件」「判断保留」を選び、判断理由や追加出典を記録します。メモ入力だけでは判断を選んだ扱いになりません。
5. 「判断記録をJSON保存」を押し、`news-now-review-records.json` を保存してCodexに渡します。ファイルを保存できたことを確認してから画面を閉じてください。
6. 続きを確認する場合は保存済みJSONを読み込みます。同じ標本の記録は読み込んだ内容で置き換わります。事前に現在の記録をJSON保存してください。

端末の下書き保存は補助機能です。ファイルを移動した場合やブラウザの設定によって使えないのでJSON保存を優先してください。画面そのものは通信せず、出典リンクを押した場合だけ外部サイトへ移動します。今回の検証では出典リンクを開いていません。

保存するJSONは `schema=news-now-review-v1`、評価ファイルと各根拠のハッシュ、事件ID、判断、メモ、確認日時、本文確認フラグを含みます。正解データや運営者の本番振り分け設定とは別の確認記録です。勝手に `evaluation.json` を変更しません。古い評価ファイル・別の事件ID・不正な形式は一括拒否します。
