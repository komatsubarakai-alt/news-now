# AI前の対象分野仕分けと完全一致代表化（隔離試作）

## 境界

`pre_ai.py` は標準ライブラリだけで動く独立した処理計画です。本番の収集、
現在地生成、追跡、Actions、予算、UI、キャッシュ検証には接続していません。
ネットワーククライアント、事件統合、進展追加、公開承認、公開JSON出力はありません。
実データ・実案件の集計・診断・SQLite・HTMLはこのPRに含めません。

```text
保存済み収集記事/現在地待ち（読み取り）
  → 記事版付きの分野仕分け
  → タイトル全文・RSS配信元文字列・日本時間の日付の完全一致代表化
  → 隔離されたAI仕事候補と元グループへの対応表
  → 将来の接続箇所（現在は dispatch_enabled=False）
       元の記事版と引用・対象事件に基づく既存安全検証が別途必須
```

## 分野仕分け

- 出力は `inside`（対象内の保護信号）、`outside_candidate`（対象外候補）、
  `hold`（判断保留・情報不足）。見出し/RSSに保護信号があっても事実確認済みとはしません。
- 犯罪・事故・災害・政策・制度・組織問題・公共施設などの保護を先に判定。
  通常スポーツ、販促、単純催事、芸能の対象語と報道/告知の文脈が揃った場合だけ候補にします。
  学校・医療・行政関係・施設・環境など判断が難しい文脈は保護/保留します。
- 網羅性より取りこぼし防止を優先。商品・行楽等の全候補を自動抽出できる実装ではありません。
- 判定理由、実際に一致した保存文字列、記事版、ルール版と実装ハッシュ、
  再確認条件を保持。本文確認済み・安全な除外確定にはしません。
- 対象外候補は可逆な別待機。削除/処理完了ではありません。混在グループは残します。
- 既存事件の対応がある候補は確認待ちに保護。明示的な運営者変更は版IDと判断記録IDが必須。

## 完全一致代表化

タイトル全文と `rss_source.name` は保存文字列をそのまま比較します。
Unicode変換、空白除去、媒体末尾の除去、URL解決はしません。
日付はタイムゾーンのあるISO/RSS日時を日本時間へ変換して比較します。
配信元・日時が不明/競合の場合は代表化しません。

本文・転送先確認は、この代表化方針では必要としません。ただし各組に
「同日同タイトルでも別記事の可能性」「本文・事件の同一性未証明」を保存します。
代表はURL文字列の昇順、同値なら記事版ID順。入力順に依存しません。
同じURLに複数版がある場合は、そのURLの各版を代表化から外します。
同URL同版の処理段階間重複と、別URLの代表化による削減は別に扱います。

`event_bindings` と `separate_pairs` で既知の別事件を渡します。グループ自身の
`event_id/event_ids` も保護します。異なる事件対応集合や別事件指定のある組は、
組全体を代表化しません。共有記事の複数事件IDは保持し、記事一致から事件を統合しません。
古いAIの別事件回答を自動的に確定判断として渡してはいけません。

既存グループ自体は統合しません。全非記事コンテキストと代表化後の記事集合が
一致する場合だけ、AI仕事候補に参照先を設けます。記事件数フィールドは投影で再計算し、
元の値は原本に保持します。異なる事件・判断・根拠コンテキストはまとめません。

## 保存・取消し・改訂

`open_store` は一時SQLite用。リポジトリ内DBは拒否します。呼び出し側は
一時フォルダーを必ず指定し、本番DBを渡してはいけません。
`save_plan` は追記専用の `pre_ai_receipts` に、操作ID・入力ハッシュ・記録日時・
全原本・仕分け・対応表を1トランザクションで保存します。
同一操作同一入力は再利用、同じ操作IDで変更入力は拒否。保存失敗はロールバック。
入力やルールが変わったら新操作IDで再計画し、旧記録は残します。

記事URL・版・公開/収集日時・他の未知フィールドも全出現記録に保存します。
`restore` は元グループ全件を復元、`disabled_cohorts` は指定組だけ代表化解除。
`is_current` は版・ルール・事件対応・運営者指定の変化を照合します。
旧対応表を新記事版へ自動流用しません。古い承認・AI回答も引き継ぎません。

## 既存機能への将来の接続条件

- この仕事投影を公開JSONや既存待機JSONへ直接保存してはいけません。
- 別URLの記事版・引用・記事事件対応を代表の内容で上書きしてはいけません。
- 代表化はAI回答の完全一致キャッシュキーになりません。元の要求・記事版・
  検証条件・根拠検証を維持し、別版への回答再利用を認めません。
- B案の最古/続報候補/通常枠、期限到来予定の最低枠、再試行抑止、
  日0.20ドル/月5ドルの保護は変更しません。統合接続は別途承認と検証が必要です。
- 既知の別事件・共有記事・運営者判断を渡す正式な読み取りアダプター、
  元版ごとの引用検証、改訂無効化、キュー公平性の検証が本番接続の阻止条件です。

## テスト

架空データのみ：

```sh
python -m unittest discover -s experiments/engine_v2 -p test_pre_ai.py -v
python experiments/engine_v2/run_offline.py
```

分野保護・根拠不足、厳密文字列/日本時間、メタデータ欠落、別事件・共有記事、
同URL改訂、代表変更・取消し・原本復元、版拘束の運営者指定、古い記録拒否、
再起動・保存失敗・再実行・二重記録防止・既存表非変更を検証します。
実AI精度、実料金削減、本文同一性、Android UIは今回の測定対象外です。
