# 下書き確認型の運営者UI（隔離試作）

作業元：Draft PR #17 `2f83b3e33ec63269ca69b3bd955fa2ba52ebd857`。変更は `experiments/engine_v2/` のみ。実AI・外部ニュース取得・Actions手動実行・本番反映・マージは行わない。

## 操作の違い

以前は進展の事実・以前との差・段階を手入力し、判断を切り替えると理由の選択が解除された。今回は最初に簡潔な比較表を表示し、判断材料と記事カードの詳細は折りたたむ。「同じ事件」を選んだ場合だけ進展を選び、「進展あり」の場合だけ下書きの取り込み・編集・引用選択・重複確認・任意の発生日時を表示する。

「下書きを入力欄に取り込む」で候補の事実・差分・段階を入れ、必要な部分を修正する。空でない入力を異なる提案に置き換える場合は確認する。**事件の同一性、引用のチェック、重複確認、発生日時、公開承認は自動選択しない。** 下書きは取り込み後も未確認。引用と段階に根拠が不足する場合は再確認待ちとなる。

理由の選択は判断別に保持し、前の判断に戻すと復元する。自由記述・進展入力も切替で失わない。保持先は事件ID・確認作業・記事／根拠コンテキスト・下書きIDで分離し、別事件や新しい記事版には流用しない。ローカル操作画面はタブのsessionStorage、閲覧専用HTMLは画面内メモリーだけで保持する。閲覧専用HTMLは判断や承認を保存できず、再読み込みで編集は失われる。

下部ナビは引き続き通常配置。理由候補は48px以上の操作領域を保ちながら余白を縮める。キーボードと重なる固定下部ボタンは作らない。画面全体が常に短くなるという主張はしない。必要な入力を選択に応じて表示し、引用には折りたたみからアクセスする。

## 下書きの生成・再利用と根拠

`operator_support.py` は通信機能を持たない純粋な投影。現在の保存引用と比較注釈から一致点・相違点・同一性の材料・別事件の可能性を整理する。段階は引用中の限定語を候補として検出し、保存済みAI回答で裏付けられる候補があれば再利用する。ルールによる整理をAI生成と偽らない。

AI再利用は、同じ事件・同じURL、現在版の文字列一致引用、現在有効な依存根拠、取消し等がない状態を確認する。不成立回答・古い版・別URL・取消し済みの判断は使わない。既存AI回答の値は「提案・未確認」であり、採用・正解・出典確認にはしない。対応づけのない汎用AIキャッシュを推測で接続しない。新しいAPI呼び出しや失敗回数・予算枠の消費はない。

新しい事実の候補は引用をそのまま使用し、以前との差は保存段階と引用中の候補を比較する未確認の案文。時系列の正しさや重要な進展を自動確定しない。既存の進展との引用重なり・同じ段階は重複候補として表示するだけで、別人物の起訴等もあり得るため人が確認する。出来事の発生日時を公開日時から埋めない。

架空データには保存済み模擬AI回答1件を追加し、再利用を実演した。実AIによる生成精度・運営負担削減率は測定していない。

根拠記事カードでは見出し・媒体・公開日時・発生日時の記述（明示注釈がある場合だけ）・引用・URL・本文取得状態・文字列照合・出典確認状態をまとめる。保存本文との一致と出典確認は別に表示する。出典を実際に確認していないため「未検証」とする。共有記事は事件別の引用・下書き・入力・確認記録を分離する。

## 保存と障害時の安全性

元の提案はクライアントから送られた文章を信用せず、サーバーが現在の資料から再構築した下書きIDと照合する。`ui_review_details` と判断IDの参照記録に、元の提案・再利用AI判断ID・記事版・引用ID・取り込み項目・運営者の最終入力を分けて保存する。理由・確認日時・操作ID・履歴は既存経路を維持する。

同一性と進展は従来の別フィールドを維持。「進展なし」は選択理由から `no_new_facts` / `same_report` / `commentary` / `already_recorded` を別々に記録し、複数選択も保持する。自由記述だけで種類を推測しない。

保存は参照記録のみ。事件統合・新事実採用・進展回数追加・公開承認を実行しない。既存の引用・根拠・矛盾・運営者指定先・記事版・保存前検証・訂正アラート・承認失効・トランザクションを緩めない。旧クライアントの参照記録には下書きIDを必須化せず、既存互換性を維持する。下書きを確認したという履歴を、下書きIDなしに作らない。

保存応答が不明な場合、新しい操作IDで再送しない。入力を保持し「未完了の操作を同じ番号で確認」で同じ記録を照会・再試行する。明確な4xx拒否は修正可能な状態へ戻す。保存失敗を成功表示にせず、作業が一覧から消えた場合も停止メッセージを上書きしない。確認成功時は過去のエラー詳細を閉じる。

## 受け渡しと残る課題

今回は新たなサイト配信・既存の別サイトURL更新は行わない。コミットはPR #17の作業ブランチだけに置き、Draft・未マージを維持する。本番JSON・Actions・日0.20ドル／月5ドルの予算設定は変更しない。
